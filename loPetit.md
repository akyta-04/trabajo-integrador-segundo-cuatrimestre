# Los dinamitas

¡Bienvenidos a **Los dinamitas**!

## Descripción

**Los dinamitas** es un proyecto creado para compartir nuestro trabajo expositivo, veremos una base de datos de enfermedades argentinas e instituciones, diagrama relacionales, diagrama de entidad-relacion y una documentacion.

El objetivo es crear un espacio sencillo, amigable y fácil de utilizar.

## Objetivos del proyecto dinamita

- Aprender nuevas cosas sobre las enfermedades y las instituciones.
- Crear un proyecto organizado.
- tener un espacio de aprendisaje
- tratar de que todos sepan sobre las enfermedades y las instituciones

## Características

- Diseño simple y fácil de entender.
- Código organizado.
- Posibilidad de agregar nuevas funcionalidades.
- Proyecto en constante desarrollo.

## 🛠️ Tecnologías utilizadas

Las tecnologías utilizadas dependerán de las herramientas elegidas para desarrollar el proyecto.

- HTML
- CSS
- JavaScript

## 🚀 Instalación y uso

1. Cloná este repositorio:

   ```bash
   git clone URL-DE-TU-REPOSITORIO
   ```

2. Entrá en la carpeta del proyecto:

   ```bash
   cd hi-my-friends
   ```

3. Abrí los archivos del proyecto y comenzá a utilizarlo.
